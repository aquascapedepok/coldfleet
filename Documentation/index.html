ColdFleet — Documentation & User Guide

Cold Chain & Reefer Fleet Management Dashboard Template.

Key Features:

  • Interactive Fleet Live Tracking Map (Leaflet.js + OpenStreetMap)
  • Multi-Zone Cargo Temperature Telemetry (ApexCharts)
  • Public Consignment Tracking Portal (AWB Status)
  • e-PoD 4-Stage Kanban Dispatch Workflow
